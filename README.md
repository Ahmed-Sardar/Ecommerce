# MERN Amazon Clone

A fully functional e-commerce platform built with the MERN stack (MongoDB, Express, React, Node.js).
Generated by Google DeepMind Agent.

## Features
- Full featured shopping cart with Redux
- User profile with orders history
- Admin product management (Create, Update, Delete)
- Admin user management
- Admin order details page (Mark as Delivered)
- Cloudinary Image Upload integration (Fallback to local)
- Checkout process (Shipping, Payment Method, Place Order)
- PayPal / Credit Card integration (Simulation/Stripe Elements ready)
- Database seeder (50+ products & users)
- Product Search & Pagination
- Product Reviews

## Setup Instructions

### 1. Backend Setup
1. Go to `backend` directory: `cd backend`
2. Install dependencies: `npm install`
3. Create a `.env` file based on `.env.example` and fill in your values.
    - **Important**: For image uploads to work in production, add `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, and `CLOUDINARY_API_SECRET`.
    - If Cloudinary keys are missing, local storage `uploads/` will be used.
4. Run seed script: `npm run data:import`
    - This will populate the database with Admin/User and 50 dummy products.
    - Admin credentials: `admin@example.com` / `password123`
    - User credentials: `user@example.com` / `password123`
5. Start server: `npm run dev`

### 2. Frontend Setup
1. Go to `frontend` directory: `cd frontend`
2. Install dependencies: `npm install`
3. Start dev server: `npm run dev`
4. Access app at `http://localhost:5173` (or port shown in terminal).

## Testing
- **Backend Tests**: Run `npm test` in `backend/` directory.
- **API Testing**: See `curl_commands.md` in the root for sample requests.

## Deployment
- **Backend**: 
    1. Create Heroku/Render app.
    2. Set environment variables (MONGO_URI, JWT_SECRET, etc.) in dashboard.
    3. Deploy code.
- **Frontend**:
    1. Create Vercel/Netlify app.
    2. Set `VITE_API_URL` to your backend URL (if not proxying).
    3. Deploy code.

## Folder Structure
- `backend/`: Server, Routes, Models, Controllers.
- `frontend/`: React App, Redux Slices, Screens, Components.

## Notes
- Payments are simulated in `OrderScreen.jsx` logic for demonstration.
- Stripe/PayPal dependencies are installed for further integration.
